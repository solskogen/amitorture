# flags (module id 3, AMT_PH_BARE)

Condition codes as consumers see them. All sequences are in `disk/modules/flags_asm.s` (68000 ISA) and `flags_010.s` (MOVE from CCR). Expected values come from a C model of the M68000 Programmer's Reference Manual (PRM) rules in `flags.c`. Each table case runs once and is compared with the model. It then runs again under `amt_hot()`, so a later (possibly JIT-compiled) pass must give the same table. A failure names the first bad entry (inputs in `in`, expected/got words), the number of bad entries, and whether it failed on the first pass or a repetition (`ctx.pass`, `ctx.hot_iter`). CCR bits: X=$10 N=$08 Z=$04 V=$02 C=$01. `sr_hi` is SR & $FF00 in the bare phase ($2000).

| case | intent | rule (manual) | a failure usually means |
|---|---|---|---|
| `sr_upper_bare` | MOVE from SR once at module start must read $2000 in the bare phase; every expected SR in this module uses $2000 as its upper byte (not a read-back) | CONTRACT section 10 (bare phase SR = $2000); PRM 1.3.2 SR layout | MOVE from SR returns a wrong system byte (S/T/M/IPL or reserved bits), or the runtime left the wrong SR |
| `scc_all` | all 16 Scc after one MOVE to CCR, for all 32 XNZVC values; SR read after each | PRM Table 3-19 conditions; Scc affects no flags | wrong condition decode (often GE/LT/GT/LE or HI/LS), or Scc clobbering lazily held flags |
| `bcc_all_short` | Bcc.s for conditions 2-15 + BRA, all 32 CCR values, 16 branches after one MOVE to CCR | PRM Bcc; Bcc affects no flags | condition decode bug in the branch path (JIT block end), or the branch materialising flags wrongly |
| `bcc_all_word` | same with Bcc.w | PRM Bcc | as above, 16-bit displacement path |
| `dbcc_all` | DBcc for all 16 conditions and 32 CCR values, counter start 1 and 0 (expiry), upper word $1234 | PRM DBcc: cc true = no-op; else Dn.w-1, branch unless -1; no flags | condition test inverted, counter decremented when cc true, upper word changed, or loop-exit flags lost |
| `ccr_imm_ops` | ORI/ANDI/EORI #imm,CCR, 12 immediates (incl. $FF, $E0) x 32 start values | PRM ORI/ANDI/EORI to CCR; CCR bits 7-5 read 0 | upper bits kept in CCR, or the op acting on stale flags |
| `move_to_ccr` | MOVE to CCR from Dn (all 256 low bytes, upper $A5), (An)+ (random words), #imm | PRM MOVE to CCR: low byte used, upper byte ignored | upper byte of the source or SR bits 7-5 leaking into the CCR |
| `move_sr_reserved` | MOVE to SR with reserved bits 11 and 7-5 set, read back by MOVE from SR (Dn and memory) | PRM 1.3 SR layout: unimplemented bits read 0 | reserved SR bits stored |
| `move_from_ccr` | MOVE CCR,Dn / MOVE CCR,(An); CCR unchanged after (68010+, skip on 68000) | PRM MOVE from CCR (68010+): zero-extended CCR | upper byte not zero, or flags changed |
| `preserve_nonflag` | 31 instructions that must not affect the CCR (MOVEA, LEA, PEA, ADDA, SUBA, ADDQ/SUBQ An, EXG x3, MOVEM x4, LINK/UNLK, MOVE USP, NOP, BSR/JSR/RTS, BRA, JMP, DBF expired/taken, Scc, MOVE SR), plus SWAP (X kept, N/Z set, V/C cleared), for all 32 CCR values | PRM per-instruction "Condition codes: not affected" | emulator or JIT computes flags for an instruction that has none (classic: ADDQ to An, ADDA, LEA), or SWAP touching X |
| `x_vs_c` | 32 instructions that set C (or nothing) but never X (CMP/CMPI/CMPA/CMPM, TST, AND/OR/EOR/NOT/CLR/MOVE/MOVEQ/EXT, SWAP, MUL/DIV, BTST/BSET/BCHG/BCLR, ROL/ROR, ADDQ/SUBQ An). X is read three ways: MOVE SR, ROXL.L #1 and ADDX.L, 4 presets | PRM: X not affected by these; N/Z/V/C per instruction | X wrongly tied to C (the lazy-flag/JIT "X = C" shortcut), BTST changing N/V/C |
| `shift_rotate_xc` | ROXL/ROXR/ROL/ROR/LSL/LSR/ASL/ASR .b/.w/.l with register counts 0-63 plus 64 and 65 (16 counts; 64/65 must act like 0/1), 2 values, X=0/1 presets; immediate forms; ROXL/ROXR.W memory | PRM: ROXd count 0 sets C=X; ROd/LSd/ASd count 0 clear C; ROd never changes X; LSd/ASd set X=C; ASL sets V if the MSB changes at any time; register count mod 64 | count-0 cases, count >= operand size, ASL V, X handling of ROd |
| `trap_rte_ccr` | for all 32 CCR values: TRAP #1 (handler EORI #$1F,CCR; RTE), TRAP #2 (handler flips the stacked SR's CCR), TRAP #3 (handler reads SR), TRAPV (V set: vector 7) + taken count | PRM/UM exception processing: SR copied, S set, T cleared, CCR unchanged on entry; RTE restores the stacked SR; TRAPV traps iff V | flags not saved/restored across exceptions, stacked SR change ignored, TRAPV condition wrong |
| `addx_reg4` / `subx_reg4` / `negx_reg4` | 128-bit ADDX/SUBX/NEGX, 4 longs fully unrolled in registers, 7 vectors x 5 presets (Z=0/1, X=0/1) | PRM ADDX/SUBX/NEGX: X in and out; Z cleared if nonzero, otherwise unchanged | carry not chained through X, Z set by a zero partial result (it must only ever be cleared) |
| `addx_mem_l8` / `_w8` / `_b8`, `subx_mem_l8` / `_w8` / `_b8`, `negx_mem_l8` | 8-element -(An),-(An) chains in a DBF loop (DBF keeps flags across the loop branch) | same rules; -(An) predecrement by size | memory form or byte/word size wrong, flags lost at the loop back-branch (JIT block boundary) |
| `roxl_chain_w8` / `roxr_chain_w8` | 128-bit shift by 1 with ROXL.W -(An) / ROXR.W (An)+ in a DBF loop | PRM ROXd memory form: shift by 1, X/C = bit out | X not carried between words |
| `roxl_chain_l8` / `roxr_chain_l8` | 256-bit shift by 1: MOVE.L to Dn, ROXL/ROXR.L #1, MOVE.L back, DBF | PRM: MOVE keeps X and sets N/Z, clears V/C | MOVE clobbering X (lazy X derived from C) |
| `addx_mem_l8_irq` | addx_mem_l8 with a level 1 SOFTINT raised (INTREQ via MOVEM, no flag change) right before the chain | interrupts save/restore SR (PRM/UM) | X/Z lost when an interrupt lands inside a flag chain |
| `addx_mem_l8_irq_delivered` | every SOFTINT raised above produced exactly one level 1 interrupt | HRM: INTREQ bit 2 + INTENA = level 1 interrupt | lost or duplicated interrupt (not a flags bug) |
| `across_none` | 23 flag producers (ADD/SUB/CMP .b/.w/.l, NEG, ADDX/SUBX/NEGX, AND, OR.W, LSL/ASR/ASL/ROXL/ROXR #1, MULU, TST, none) x 12 operand pairs x 4 presets; consumers right after: MOVE SR, all 16 Scc, X via ADDX, result | PRM per-instruction condition codes | wrong flags from the producer itself (baseline for the other across_* cases) |
| `across_nonflag` | as across_none with 20 non-flag instructions in between (MOVEA, LEA, ADDA, SUBA, ADDQ/SUBQ An, EXG, MOVEM, PEA, LINK/UNLK, NOP, MOVE USP, Scc, MOVEM.W to memory) | those instructions affect no flags | lazy flags overwritten by a non-flag instruction's host computation |
| `across_branch` | taken and not-taken Bhi.s, Bmi.w, then a Bvs/Bcs/Beq/Bge chain in between | Bcc affects no flags | flags lost across a JIT block boundary on either branch path |
| `across_bsr` | BSR.W and JSR to subroutines (LEA/EXG/MOVEA/ADDQ An) and RTS in between | BSR/JSR/RTS affect no flags | flags lost across a call/return |
| `across_dbcc` | DBF loop (4 passes) then DBEQ loop (exits at once if Z, else expires; d6 checked) in between | DBcc affects no flags | flags lost at a DBcc loop exit, or DBEQ testing stale flags |
| `across_trap` | two TRAP #1 (handler EORI #$1F,CCR; RTE) in between | RTE restores SR | flags not saved/restored around a trap in the middle of a lazy-flag sequence |
| `across_irq` | SOFTINT raised after the producer, 48-pass DBF loop: the level 1 interrupt (C hook) hits between producer and consumer | interrupt entry/RTE preserve SR | flags lost when an interrupt arrives while flags are pending |
| `across_irq_delivered` | each SOFTINT raised in across_irq gave exactly one level 1 interrupt | HRM interrupts | lost/duplicated interrupt |

# cpu_basic (module 2): integer instruction set

Generated by `tools/gen_cpu_basic.py`, which also holds the reference model. Each case runs every test vector of its templates once (compared with the table), then `amt_hot()` re-runs vector `i*7919 mod n` for i = 0..amt_hot_reps() (a stride, so a large case is hot-checked across all its vectors; interpreter-vs-compiled check). A failure lists the instruction text and opcode words, the inputs, the expected and actual outputs and the mask of defined CCR bits (`ccr_mask`; undefined flags are masked out). Register values marked `@m` are offsets from the module's memory window base M, `@anchor` offsets from a label in the snippet.

Cases whose templates all need a CPU the machine lacks report `skip`; the CPUs a template runs on are fixed in the generator (e.g. MOVEP, CMP2/CHK2, CAS2, 64-bit MUL/DIV are not run on the 68060, where they are unimplemented and trap: exceptions module).
